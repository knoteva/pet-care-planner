# Pet Care Mobile Instructions

This package contains the Expo mobile app for Pet Care Planner.

- Keep user-facing UI text in Bulgarian.
- Keep code identifiers, route names and service names in English.
- Use Expo Router for screens.
- Use the Next.js backend through REST API endpoints.
- Send Bearer JWT tokens for protected requests.
- Keep admin and group manager tools out of the mobile MVP unless explicitly requested later.
- Add API client and auth storage helpers under `src/services`.
- Use Web-compatible dialogs or inline UI states when Expo Web cannot use a native API cleanly.
